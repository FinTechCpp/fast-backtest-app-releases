Guide de Démarrage Rapide

Lancez votre premier backtest en 5 minutes

Étape 1

📥 Préparez vos données

Fast Backtest App utilise des fichiers CSV au format OHLC (Open, High, Low, Close). La date est en UTC+0

,date,open,high,low,close,volume 2024-01-01T09:30:00,100.5,101.2,100.1,101.0,5000 2024-01-01T09:31:00,101.0,101.5,100.8,101.3,4500

Importez vos fichiers CSV via le menu Données > Importer

💡 Astuce: Utilisez le notebook Jupyter fourni (Notebooks/fetch_by_ibkr.py) pour télécharger des données historiques depuis Interactive Brokers.
Étape 2

⚙️ Configurez les paramètres généraux

Dans le panneau de gauche, définissez:

  • Symbole: Choisissez parmi les fichiers détectés
  • Intervalle: 10secs, 20secs, 1min, 5min, 1h, 1d, etc.
  • Période: "6M" pour 6 mois, "1Y" pour 1 an
  • Capital initial: 10000 € par défaut
  • Spread: En pour mille (0.1 = 0.01%)
  • Commission: Frais par trade
  • Levier: Limite de levier (en multiple du capital)
[Capture d'écran: Panel de configuration générale]
Étape 3

🎯 Créez votre stratégie

Cliquez sur "Ajouter une stratégie" puis "Modifier" pour configurer:

Exemple: Stratégie RSI simple

  1. Nom: "RSI Mean Reversion"
  2. Filtres d'achat (LONG):
    • RSI(14) < 30 (survente)
  3. Filtres de vente (SHORT):
    • RSI(14) > 70 (surachat)
  4. Stop Loss: ATR-based, multiplicateur 2.0
  5. Take Profit: Ratio SL, 1.5:1
[Capture d'écran: Éditeur de stratégie avec filtres]
💡 Indicateurs disponibles: RSI, EMA, SMA, MACD, Bollinger Bands, Stochastic, ATR, CCI, SuperTrend, Pivot Points, et bien plus !
Étape 4

🚀 Lancez le backtest

Cliquez sur le bouton vert "Lancer le backtest". Le moteur C++ va:

  • Charger et resampler les données si nécessaire
  • Calculer tous les indicateurs requis
  • Simuler chaque trade avec spreads/commissions
  • Générer les résultats en quelques secondes
[Capture d'écran: Bouton de lancement + barre de progression]
Étape 5

📊 Analysez les résultats

Explorez les 3 onglets de résultats:

1. Statistiques

  • Profit net, Gross Profit/Loss
  • Win rate, Profit Factor
  • Sharpe Ratio, Sortino Ratio, Calmar Ratio
  • Max Drawdown et durée
  • Nombre de trades, exposition au marché
  • Distribution des trades (heatmap horaire)
[Capture d'écran: Vue des statistiques]

2. Graphiques

  • Chandelier japonais avec indicateurs overlay
  • Marqueurs d'entrée/sortie des trades
  • Courbe d'équité vs Buy & Hold
  • Zoom interactif sur trades spécifiques
[Capture d'écran: ChartView avec trades]

3. Historique

  • Table détaillée de tous les trades
  • Date entrée/sortie, prix, P&L
  • Durée, raison de clôture
  • Exportable en CSV

Installation par Plateforme

🪟 Windows

  1. Téléchargez le fichier ZIP
  2. Extrayez dans le dossier de votre choix
  3. Double-cliquez sur backtestapp.exe
# Via PowerShell: cd C:\chemin\vers\fast-backtest-app-windows .\backtestapp.exe

🍎 macOS

  1. Téléchargez et montez le DMG
  2. Glissez-déposez dans /Applications
  3. Si bloqué: Sécurité → "Autoriser quand même"
# Via Terminal: open /Applications/FastBacktestApp.app

🐧 Linux

  1. Installez les dépendances système si nécessaire
  2. Extrayez l'archive tar.gz
  3. Lancez via le script wrapper
tar -xzf fast-backtest-app-linux-*.tar.gz cd fast-backtest-app-linux chmod +x backtestapp.sh ./backtestapp.sh

Note: Le script configure automatiquement LD_LIBRARY_PATH et QT_PLUGIN_PATH.

Remarques :

  • Conservez le dossier distribué tel quel pour que les bibliothèques Qt et plugins soient trouvés correctement.
  • Si vous rencontrez des erreurs liées à des bibliothèques manquantes, vérifiez les fichiers fournis dans le dossier lib / plugins (Linux) ou la présence des DLL (Windows).

🛠️ Guide de Développement

1. Prérequis

  • CMake: 3.14+ (recommandé 4.0.3+)
  • Compilateur: GCC 7+, Clang 8+, MSVC 2019+
  • Qt: 6.8.3 (modules: Core, Widgets, Charts, Network)
  • Git: Pour les submodules

2. Structure du Projet

fast-backtest-app/ ├── backtestApp/ # Application Qt │ ├── include/ # Headers │ ├── src/ # Sources C++ │ └── CMakeLists.txt ├── ThirdParty/ │ ├── Strategies/ # Moteur de backtest C++ │ ├── ChartDirector/ # Lib de graphiques │ └── ... # Autres dépendances ├── marketData/ # Données CSV ├── Notebooks/ # Jupyter notebooks └── CMakeLists.txt

3. Build Instructions

Linux/macOS:
# Debug build ./build_and_run.sh --debug # Release build ./build_and_run.sh # Build sans lancer ./build_and_run.sh --no-run # Clean build ./build_and_run.sh --clean
Windows (Visual Studio):
# Générer les fichiers Visual Studio cmake -B build -S . -DBUILD_WITH_DEBUG=ON # Build depuis VS ou ligne de commande cmake --build build --config Debug --parallel # Ou depuis VS Code avec la tâche "build-debug-windows"

4. Architecture du Code

  • Frontend: backtestApp/src/ui/ - Widgets Qt, vues, menus
  • Backend: ThirdParty/Strategies/ - Moteur C++ de backtest
  • Utilities: backtestApp/src/components/Utils/ - DataLoader, etc.
  • Indicators: ThirdParty/Strategies/include/Indicators/ - RSI, MACD, etc.

5. Guidelines de Code

  • Suivre le style de code existant (camelCase pour Qt, snake_case pour STL)
  • Commenter les fonctions complexes
  • Utiliser des smart pointers (std::unique_ptr, std::shared_ptr)
  • Éviter les raw loops, préférer STL algorithms
  • Tester sur les 3 plateformes si possible

6. Déboguer l'Application

  • Les logs sont dans logs/backtestApp/
  • Utilisez qDebug() pour le debug Qt
  • Utilisez logger->debug() dans les stratégies
  • Configurez VS Code avec le .vscode/launch.json fourni

❓ Questions Fréquentes

Quelle est la différence entre la version stable et beta ?

Version Stable : Version testée et recommandée pour une utilisation en production. Elle a passé tous les tests et est considérée comme stable et fiable.

Version Beta : Version de développement avec les dernières fonctionnalités. Elle peut contenir des bugs et est destinée aux utilisateurs qui souhaitent tester les nouvelles fonctionnalités avant leur sortie officielle.

Quelles plateformes sont supportées ?

Fast Backtest App est disponible pour:

  • Windows: 10/11 (64-bit)
  • macOS: 11+ (Intel et Apple Silicon)
  • Linux: Ubuntu 20.04+, Debian 10+ (et dérivés)
Quel format de données est requis ?

Format CSV avec les colonnes suivantes:

timestamp,open,high,low,close,volume

timestamp: Format ISO 8601 (YYYY-MM-DDTHH:MM:SS)

Prix: Format décimal (point comme séparateur)

Volume: Optionnel

Comment charger mes propres données ?

Deux méthodes:

  1. Placez vos fichiers CSV dans le dossier marketData/
  2. Ou utilisez Menu → Données → Définir dossier personnalisé
  3. Ou utilisez Données → Importer

L'application détecte automatiquement les nouveaux fichiers.

Combien de temps prend un backtest ?

Cela dépend de:

  • Nombre de bougies (périodes testées)
  • Complexité de la stratégie (nombre d'indicateurs)
  • Puissance de votre CPU

Exemples typiques:

  • 6 mois, 5min: ~2-3 secondes
  • 2 ans, 1h: ~1-2 secondes
  • 5 ans, 1d: <1 seconde
Puis-je utiliser mes modèles de Machine Learning ?

Oui ! Fast Backtest App supporte les modèles ONNX.

  1. Entraînez votre modèle avec TensorFlow/PyTorch/scikit-learn
  2. Exportez-le au format ONNX (voir Notebooks/onnx_conversion.ipynb)
  3. Chargez-le dans la configuration de stratégie
  4. Utilisez les prédictions comme filtres d'entrée
Où trouver les logs en cas de problème ?

Les logs sont stockés dans:

  • Windows: C:\chemin\vers\app\logs\backtestApp\
  • macOS: /Applications/FastBacktestApp.app/Contents/logs/
  • Linux: ./logs/backtestApp/ ou ~/.fast-backtest-app/logs/

Format: backtestSession_HH-MM-SS.log
